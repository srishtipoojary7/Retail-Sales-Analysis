# Retail Sales Analysis and Business Insights

## Project Overview

This project analyzes online retail transaction data to identify sales trends, best-selling products, and revenue contributions by country.

## Objectives

* Explore and clean retail transaction data.
* Analyze sales revenue and product demand.
* Identify monthly sales trends.
* Compare sales performance across countries.
* Create visualizations and provide business recommendations.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

Online Retail dataset from Kaggle:

https://www.kaggle.com/datasets/vijayuv/onlineretail

## Analysis Performed

1. Dataset exploration and summary statistics.
2. Missing-value and duplicate checks.
3. Data cleaning.
4. Revenue calculation using Quantity × UnitPrice.
5. Top 10 best-selling products analysis.
6. Monthly revenue trend analysis.
7. Country-level revenue analysis.
8. Transaction revenue distribution.

## Output

The project produces a cleaned retail dataset, visualizations, and a Jupyter Notebook containing the analysis.

## Important Note

Cancelled transactions and returned goods should be examined separately before reporting final net revenue. Findings and numerical results should be verified against the notebook output.

## Conclusion

This project demonstrates practical data analysis skills, including data cleaning, aggregation, visualization, and interpretation of retail business performance.
